    How does this prediction work?
    1. Your values are sent to the Flask server (POST /api/predict-rain) and validated: each must be present, numeric, finite and physically possible. Values outside the training range are still accepted, but you get a warning because the model is extrapolating. Inputs are never clipped.
    2. The saved model pipeline is loaded from models/rain_classifier.joblib. Nothing is retrained.
    3. predict_proba returns a probability for each class. The rain column is found from the model's classes_, not assumed to be at a fixed position.
    4. The label is Rain when that probability is at or above the decision threshold{% if metrics %} ({{ (metrics.classification.threshold * 100) | round | int }}%){% endif %}. The same rule produced the test-set metrics on the evaluation page.
