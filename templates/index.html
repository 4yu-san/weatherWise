Supervised machine learning mini-project

WeatherWise: Weather Prediction & ML Analysis

Two supervised learning tasks on one weather dataset: classifying whether rain is likely, and a multiple regression that estimates cloud cover. Each task compares two models, and every number on this site comes from the training pipeline.

Predict rain See evaluation
Disclaimer: this is an educational model built for a college project. It is not an official weather forecasting service and does not use live weather data.

Task 1: Classification

The output is a category: rain or no rain. The models learn from 5 independent variables and return a probability for the rain class. A decision threshold turns that probability into a label.

Models compared: Logistic Regression and Random Forest Classifier.

Task 2: Multiple Regression

The output is a continuous number. Dependent variable Y = Cloud_Cover; independent variables X = Temperature, Humidity, Wind_Speed, Pressure. Cloud_Cover is never used to predict itself.

Models compared: Multiple Linear Regression and Random Forest Regressor.
